# 需求与验收

## 用户与范围

面向全球视频内容运营人员，输入一个带时区的发布请求，Agent 独立处理其中每个合成素材：读取、确定性审核、查询时段、根据观察继续选择工具，最终保存 SQLite 排期草稿或说明阻断原因。程序没有真实发布接口。

业务背景参考 [小影官网](https://www.quvideo.com/zh)、[产品页](https://www.quvideo.com/zh/products) 和 [浙江大学招聘页](https://www.career.zju.edu.cn/jyxt/sczp/zpztgl/ckZpgwXq.zf?zpxxbh=5C1E142D3E0DB237E0653A68DD0E9B18)，于 2026-11-01 实际打开核对。公开页面支持 AI Catch、VivaVideo、VivaCut 产品及 AI 创作、工具集成、任务执行与评测的背景；本项目的素材、授权记录、规则、排期均为合成数据。没有使用公司内部系统。

## 输入输出

`ScheduleRequest` 包含 request_id、1–10 个不重复素材 ID、渠道、市场、IANA 时区、带偏移的原时间、硬性约束、可选替代时间窗口及显式用户确认。窗口最长七天；本地偏移必须符合该时区在该瞬间的实际偏移。不存在的夏令时时间会被拒绝。例子采用 2027-01-15 的未来合成排期。

`Material` 包含题目、类型、主题、产品、市场、语言、渠道、版权状态、授权范围、标签、审核元数据和缺失项。`ReviewResult` 返回命中规则与证据。`ScheduleDraft` 分离审核状态、确认状态和保存状态，保留原时间、建议时间及确认输入证据。

CLI 最终 JSON 由工具状态和已提交数据库记录生成，包含审核、风险、原时间、建议时间、待办、保存结果、执行状态、错误、预算及 Trace 路径。模型最终自然语言不能充当保存成功的证据。

## 状态和安全不变量

| 维度 | 状态及含义 |
|---|---|
| 审核 | PASS 可继续；NEEDS_INFO 缺资料；NEEDS_REVIEW 人工复核；BLOCKED 明确阻断 |
| 确认 | ORIGINAL_REQUEST 原要求；WITHIN_FLEXIBILITY 用户允许的软时间调整；USER_CONFIRMED 精确显式确认；PENDING 待确认 |
| 草稿 | READY 占用时段的草稿；AWAITING_CONFIRMATION 不占用时段的建议草稿；二者都不是发布结果 |
| 保存工具 | SAVED、ALREADY_EXISTS、SAVE_FAILED、REJECTED_BY_POLICY |
| 执行 | COMPLETED 已处理完每个素材，可能含阻断或保存失败；INCOMPLETE 未完成或超预算；FAILED 模型、配置或运行错误 |

1. 只有 PASS 可保存；缺失许可、禁止使用、需要人工复核均不能产生可执行草稿。
2. 硬性时间的替代建议必须 PENDING；模型无权生成用户确认。精确确认只能来自原始请求。
3. 所有新写入经过 Guard，并在 `BEGIN IMMEDIATE` 事务内重新检查冲突；提交失败不返回草稿 ID。
4. 同渠道、同市场、开始时间相距严格小于 60 分钟视为冲突。CONFIRMED 正式排期和 READY 草稿占用时段；取消排期和待确认建议不占用。
5. 每个原始请求指纹和素材 ID 在数据库中最多一行；重启与并发提交仍成立。
6. 每次模型选择基于真实工具观察；live 不得隐式切换 mock。没有真实发布工具。

上述是演示业务规则，不是公司内部规则或社交平台最新官方政策。元数据审核不等于对视频画面的视觉审核。

## 六项强制验收

| 场景 | 输入 | 成功标准 |
|---|---|---|
| 正常 | M01，16:00，美东时区 | PASS，原时间真实提交 READY 草稿 |
| 缺信息 | M02，音乐许可缺失 | 补查仍缺资料；NEEDS_INFO，要求提供授权及范围，不保存 |
| 风险 | M03，明确禁止授权 | BLOCKED，不保存 |
| 冲突 | M01，18:00 硬性时间，18:00–21:00 可查窗口 | 模型观察冲突后主动另查；替代建议保留 PENDING 与原时间 |
| 重复 | 同一 duplicate 请求独立进程提交两次 | 第二次 ALREADY_EXISTS，同一 draft_id，数据库只有一行 |
| 保存失败 | PASS 空闲时段，显式事务故障注入 | 插入回滚，SAVE_FAILED，数据库零行，CLI 退出码 4 |

确定性工程测试与真实模型决策验证分别记录。实际逐项结果与证据链接见 [评估报告](03-evaluation.md)。
